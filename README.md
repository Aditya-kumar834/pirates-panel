# Pirates Babaz Panel (Vercel)

Dark device console: connect any Firebase RTDB URL, view devices (online/offline/battery/number), open SMS/OTP.

## Local
```bash
cd annebella_panel
npm install
npm run dev
```
Open http://localhost:3000

## Vercel
Import GitHub repo, Framework Next.js, Deploy.

## Use
1. Open site
2. + New Account
3. Paste Firebase URL
4. Connect → devices
5. Click SMS on a device
